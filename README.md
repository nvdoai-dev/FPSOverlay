# FPSOverlay

FPS Overlay UI

## Add the overlay to multiple scenes

Open the tool from `Tools > Add FPS Overlay`. The window lists the scenes in Build Settings with their FPS overlay status. Use `Refresh status` to check all scenes, then add or remove the overlay on each scene separately.

Scenes that are already open are marked dirty, so save them in the editor. Scenes that are closed are opened temporarily, updated, saved, and closed by the tool.

## Installation

Download the Unity package from the [Releases](../../releases) page and import it using `Assets > Import Package > Custom Package...`.
